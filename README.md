# Quiz Pythagore (Android)

Cette application Android propose un mini-quiz sur le théorème de Pythagore. Elle affiche une question à la fois, vérifie la réponse et indique le score final.

## Générer une APK

1. Installez Android Studio et le SDK Android.
2. Depuis la racine du projet, lancez :

```bash
gradle assembleDebug
```

L'APK se trouve ensuite dans `app/build/outputs/apk/debug/app-debug.apk`.
